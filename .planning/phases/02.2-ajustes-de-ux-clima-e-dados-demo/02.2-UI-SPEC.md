## Color

Dominant 60% `background`; secondary 30% `card` + 1px `border` (settings cards, weather card, chart cards, popups); accent 10% `primary` family. Destructive `errorFill` only on confirm buttons inside dialogs ("Sair da conta" confirm, "Descartar…", "Limpar pontos").

Accent reserved for (inherited list, plus these additions only):
1. Selected segment in theme/unit control and in the period chips (`primarySoft` bg + `primaryText`, inherited Tabs/Chip look)
2. Primary buttons: "Gerar dados" (dialog), "Gerar dados demonstrativos" (empty page state), "Salvar nome", "Adicionar sensor" (Análises empty)
3. Switch "on" track (`primary`) and thumb `onPrimary`
4. Ghost text actions: "Adicionar fazenda" (Perfil), "Tentar novamente" is `secondary` not accent
5. DemoBadge (`primarySoft`/`primaryText`), focused input border / web focus ring

Not accent: weather icons (own tokens), chart lines (series tokens), "Sair da conta" trigger (uses `error` text/icon, secondary button, no fill), map overlay colors (`map*`).

## Screen Contracts

### S1. Popups (UX-01) — every dialog, sheet and picker

- One look: dimmed backdrop (`overlay`), centered card, `radius.cardLg`, `card` bg, padding 24, shadow as in current `Modal`. Width hugs: `min(100% - 32, 400)`; height = content up to 80% of the screen, then the body scrolls.
- Never anchored to the bottom, never full-width, never full-height. Same on phones, tablets and desktop web (centered in the viewport, 400 max, independent of the 500px app column because RN `Modal` renders outside it).
- Pickers (`Select`, `FarmSelector`): title row + list. Up to ~5 rows the card hugs the rows; beyond that it caps at 80% and scrolls (scroll indicator visible on web).
- Dismiss: backdrop tap, X (48x48, label "Fechar"), Android back, Escape (web). Focus moves into the dialog on open and returns to the trigger on close (RN Web Modal behavior; do not override).
- Dialogs with destructive/irreversible actions never close on backdrop tap while a request is in flight.
- Button order top to bottom: confirm first, dismiss second (inherited).

### S4. Mapa monocromático (MAP-02) — both farm and sensor flows

- **Layers:** `MapLayerToggle` offers **Mapa** (default) and **Satélite**. Toggle chrome and position unchanged (02.1: top-left, inset 12, 48dp segments). A11y label "Tipo de mapa"; segment labels "Mapa" / "Satélite". Default reset to "Mapa" on each flow entry.
- **Mapa tiles (monochrome by provider, no CSS filter):** CARTO `light_all` in light theme, `dark_all` in dark theme: `https://{s}.basemaps.cartocdn.com/{light_all|dark_all}/{z}/{x}/{y}{r}.png`, subdomains `abcd`, `maxZoom 20`, `maxNativeZoom 20`. Attribution: `© <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors © <a href="https://carto.com/attributions">CARTO</a>`. Configured in `mapTiles.ts` as `TILE_LAYERS.map = { light, dark }`; the old `street` OSM layer is removed from the UI (kept only if the planner needs a CARTO outage fallback; not user-visible).
- **Satélite tiles:** Esri World_Imagery unchanged, made monochrome with a CSS `filter` on the Leaflet tile pane (`.leaflet-tile-pane`): constants `SATELLITE_FILTER = { light: 'grayscale(1) contrast(0.95) brightness(1.05)', dark: 'grayscale(1) contrast(1.05) brightness(0.65)' }` in `mapTiles.ts`. Overlays (markers, polygon, circles) live in other panes and are NOT filtered.
- **Map background while tiles load / gaps:** `scene.style.mapBg` = `colors.background` (from the theme, no literal).
- **Theme into the scene:** `MapScene` gains `theme: 'light' | 'dark'` and `layer: 'map' | 'satellite'`; `scene.style` is rebuilt from the active palette (theme-specific `map*` tokens above). Changing the app theme (Perfil or OS) re-sends the scene so the tile layer and overlay colors swap live without remounting the map, keeping center/zoom, drawn points and pending sensor. Works identically in the web `<iframe srcDoc>` and the native WebView.
- **Overlay drawing:** unchanged from 02.1 (halo + stroke + fill) using the new theme-specific tokens; they stay the brand green / sensor blue on top of grey. Existing sensors use `mapSensorExisting` (dark slate in light theme, light slate in dark theme).
- **Leaflet attribution control:** stays default and visible (bottom-right, not themed, never covered). Required by the CARTO/OSM/Esri terms.
- **Chrome:** the RN overlays (toggle, zoom, centralizar) already use `card`/`border`/`text` tokens and follow the theme.
- Reduce-motion and tile-error behavior inherited. If CARTO tiles fail to load, the existing map error state applies.

**Demo prompt (D-11):** shown automatically when the screen gains focus AND the selected farm has >=1 sensor AND `demo_data_generated_at` is null AND it has not been dismissed in this visit. Uses `ConfirmDialog` tone primary:
- Title: "Gerar dados demonstrativos?"
- Message: "Vamos criar 30 dias de leituras simuladas para todos os sensores de {Fazenda}, para você ver os gráficos. Os dados ficam marcados como demonstrativos."
- Confirm "Gerar dados" (loading "Gerando dados…") · Cancel "Agora não" (closes; asked again next visit; page shows the manual button).
- Errors inside the dialog (`Notice error`, dialog stays open, retry possible): generic "Não foi possível gerar os dados. Verifique sua internet e tente de novo."; rate-limited "Os dados acabaram de ser gerados. Aguarde um minuto para gerar de novo."; not owner / not found "Não encontramos esta fazenda. Volte e escolha a fazenda de novo."
- Success: dialog closes, queries for Início/Monitoramento/Análises invalidated, `Notice success` appears (live region polite), charts load.
- "Regerar dados" -> `ConfirmDialog` tone primary: title "Gerar os dados de novo?", message "Os dados demonstrativos atuais dos sensores serão trocados por novos. Leituras reais não são alteradas.", confirm "Regerar dados" (loading "Gerando dados…"), cancel "Manter dados atuais". Same error copy.
- Selecting another farm re-evaluates the prompt for that farm (once per visit per farm).

**`SensorChartCard`** (`Card` padding 16, gap 12):
1. **Header row** (gap 12, `alignItems: center`): icon circle 40 (`background`, type icon 20 `textMuted`: `Thermometer` / `Droplets` / `Sprout`) -> column `flex: 1`: Body 16/600 sensor name (`numberOfLines 2`) + Label 14 muted type name ("Temperatura" / "Umidade do ar" / "Umidade do solo") -> right column (end-aligned): Heading 20/600 numeric latest value with unit (temperature via `formatTemperature`; humidity/soil `{n}%`) + Caption muted "Última leitura".
2. **Chart** (`LineSeriesChart`): plot height 180; width measured with `onLayout` (card inner width minus 40 y-axis gutter), no horizontal scroll, no page horizontal scroll at 360. Line 2px in the type's series token, no area fill, no curve smoothing artifacts (`curved` off); data dots (radius 3) only when <=24 points (24h), otherwise hidden. Y axis: 4 labels Caption `textMuted`, auto-range with 10% padding, unit omitted in labels (unit shown in header and stats). X axis labels Caption `textMuted`: 24h -> "08h, 14h, 20h…" every 6h; 7 dias -> weekday short ("Qua"); 30 dias -> "dd/MM" about every 7 days. Grid: horizontal lines 1px `border`, no vertical grid. Data granularity: 24h = hourly (24 pts), 7 dias = 3-hour buckets (56 pts), 30 dias = 6-hour buckets (120 pts), bucket value = mean.
3. **Ideal range** (only when the sensor/farm has thresholds): two horizontal reference lines (min, max) dashed 1px `warning` across the plot, and a legend row under the chart: dashed swatch 16x0 border `warning` + Caption muted "Faixa ideal: {min}–{max} {unit}". Range lines are also described in text in the stats block, so color is never the only signal.
4. **Interaction:** touch/drag or hover (web) shows a pointer line + tooltip chip (`card` bg, 1px `border`, radius 8, padding 8, shadow like map controls) with Body 16/600 value and Caption muted "{dd/MM HH:mm}". Tooltip clamps inside the plot. No tooltip needed for a11y (stats carry the information).
5. **Stats row** (divider above, 12 gap): three `flex: 1` columns: Label muted "Mínimo" / "Média" / "Máximo" over Body 16/600 numeric values with unit.
6. **Range status line** (only with thresholds): all buckets inside -> `CircleCheck` 16 `success` + Label `successText` "Dentro da faixa ideal no período"; otherwise `TriangleAlert` 16 `warningText` + Label `warningText` "{n} leituras fora da faixa ideal" (n=1: "1 leitura fora da faixa ideal"), counted on raw readings.
7. **A11y:** chart area is one `accessible` View, role `image`, label "Gráfico de {Nome}, {período}. Mínimo {x}, média {y}, máximo {z}, última leitura {w}." Inner SVG hidden from the a11y tree (`importantForAccessibility="no-hide-descendants"`, `accessibilityElementsHidden`). Header and stats stay reachable text.
8. **States per card:** loading -> static skeleton (header bars + 180 block + 3 stat bars, `background` fill); no readings in the period -> chart area replaced by `BarChart`-free empty block (minHeight 120, centered): `ChartLine` 24 `textMuted` + Label muted "Sem leituras neste período." (stats and range line hidden); per-card error is not used (page-level `ErrorState`).

## Interaction & Accessibility

- All new pressables >=48x48 (rows 56, chips 48, segments 48, dialog buttons `md` 48); pressed feedback via `background` / `primarySoft`; web focus ring inherited (2px `primaryText`, offset 2).
- Web keyboard: Tab order follows visual order; Escape closes dialogs; Space/Enter toggles Switch rows and chips; arrow keys not required.
- Dialogs: focus trapped, title is `accessibilityRole="header"`, results of async actions announced via live regions.
- Weather and charts expose text equivalents (labels above); icons decorative (`accessibilityElementsHidden`).
- Status never color-only: Switch has "Ligado/Desligado", range status has icon + text, selected segments have weight 600 + tint.
- No new motion. `isAnimated={false}` on charts; skeletons are static.
- 360px: weather strip scrolls only inside the card; chart cards have no horizontal overflow; popups 328px wide; Perfil rows wrap description text (no truncation of labels).
- Large font (200%): rows grow in height; day column keeps 60 width, weekday allowed to wrap; stats rows wrap to a column when they would overflow (flexWrap).
- Haptics: none.
