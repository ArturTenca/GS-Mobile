## Behavior

- States: loading "Carregando análises…"; ErrorState with retry; zero farms "Cadastre sua primeira fazenda" + Adicionar fazenda; farm with zero sensors "Cadastre um sensor para ver análises" + Adicionar sensor (`/adicionar/sensor?farm=`) or "Esta fazenda ainda não tem limite no mapa." without action; no popup there. FarmSelector stays visible in the zero-sensor state when there are 2+ farms so the user can switch.
- Content: FarmSelector (2+ farms) or muted farm name; "Período" + PeriodChips (default 7 dias, state kept in-screen so scroll position is preserved); SectionHeader "Gráficos dos sensores" with "Gerar dados demonstrativos" / "Regerar dados"; DemoBadge when any sensor is demo; success Notice; one SensorChartCard per sensor (gap 16) with offset, thresholds range and temp unit.
- Prompt: opens when focused and shouldPromptDemo is true. "Agora não" adds the farm to a visit-only dismissed list (reset by useFocusEffect). Generation uses useGenerateDemoData (inFlight guard, invalidates sensors/home/farms/readings); dialog shows "Gerando dados…" and cannot be dismissed while loading; errors render the hook's mapped PT-BR message inside the dialog and allow retry.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug prevention] Prompt derived instead of opened in useEffect**
- **Issue:** Plan suggested a useEffect that opens the dialog; that pattern triggers the project's react-hooks/set-state-in-effect lint rule and can double-open.
- **Fix:** Dialog open state = manual dialog kind or (focused && shouldPromptDemo). Same behavior.
- **Commit:** 6cc2ec6

**2. [Rule 2 - Correctness] Prompt suppressed after success and offset error surfaced**
- Farm id is marked handled after a successful generation so the popup cannot reappear when `demo_data_generated_at` is not yet visible; the demo offset query error is included in the page ErrorState so cards cannot be stuck in skeleton.
- **Commit:** 6cc2ec6
