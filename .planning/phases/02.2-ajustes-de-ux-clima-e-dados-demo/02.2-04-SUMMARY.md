## Details

- `validateFullName` trims, collapses inner whitespace, enforces 1..120 (DB check).
- `updateProducerName` filters by the auth user id, uses `.select('full_name').single()`, then best-effort `auth.updateUser({ data: { name } })`; any failure throws the verbatim PT-BR ServiceError.
- `useUpdateProducerName` returns `{ save, isSaving, errorMessage, reset }`, invalidates `['producer']`.
- `SettingsRow`: minHeight 56, trailing `none | chevron | external | switch`, Ligado/Desligado text next to the switch, `accessibilityRole="switch"` + `checked`.
- `Button tone="danger"` only changes fg to `colors.error` for the secondary variant.
- Perfil: only Conta shows LoadingState "Carregando perfil…" / ErrorState with retry; Aparência, Fazenda, Notificações, Unidades, Dados, Sobre and Sair render independently. "Salvar nome" appears only when the normalized value is valid and differs from the saved name; "Nome atualizado." shows until the next edit. Web adds "Notificações push só no app do celular.". External links are hardcoded https constants opened with `Linking.openURL` in a silent try/catch.
