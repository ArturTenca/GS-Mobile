# Phase 02.2 Plan 08: Chart UI Summary

This plan adds the chart UI for Análises. It installs react-native-gifted-charts 1.4.81 and expo-linear-gradient 58.0.4 with `npx expo install`, then builds three components. `LineSeriesChart` measures its own width and draws a line chart with no horizontal scroll. `SensorChartCard` shows each sensor's chart with min/média/máximo, the ideal range and its own loading, empty and error states. `PeriodChips` is a radiogroup for the period.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] X-axis labels rendered through labelComponent instead of xAxisLabelTexts**
- **Found during:** Task 1
- **Issue:** gifted-charts makes each x label box as wide as the spacing between points. At 56 to 120 points on a narrow card that is 2 to 6 px, so labels like "Qua" or "12/11" would be clipped. The only built-in way to widen the box, `labelsExtraHeight`, also changes the chart's height.
- **Fix:** Points that have a label get a `labelComponent` that renders a 48px box centered on the point. The `xLabels` prop and `buildXLabels` output are unchanged.
- **Commit:** 4cc2b34

**2. [Rule 2 - a11y] Chip gained an optional `role` prop**
- **Found during:** Task 2
- **Issue:** Chip always used accessibilityRole button with a `selected` state, so screen readers could not announce it as a radio option inside a radiogroup.
- **Fix:** Added `role?: 'button' | 'radio'`. With the radio role, Chip sets `accessibilityState.checked`. The default stays button, so the look and existing behavior do not change.
- **Commit:** 36232d5
