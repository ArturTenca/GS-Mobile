# Phase 02.2 Plan 05: Open-Meteo weather forecast on Início Summary

Início now shows the real Open-Meteo forecast for the selected farm (now block with condition icon, humidity, wind, rain, and a 7-day strip with weekday, icon, max/min and rain chance) through a validated fetch adapter with rounded coordinates, a React Query hook, and a demo/no-location fallback; all Início temperatures follow the °C/°F preference.

## What was built

- **`src/services/weather.ts`**: `WEATHER_BASE_URL`, `roundCoord`, `Forecast`/`ForecastCurrent`/`ForecastDay` types and `getForecast(lat, lng)`. It sends only rounded latitude/longitude (2 decimals) plus the D-05 params (`current`, `daily`, `timezone=auto`, `forecast_days=7`), with no key and no user data. It aborts after 8 s, checks that the blocks exist, that the daily arrays are as long as `daily.time`, and that numbers are finite (`precipitation_probability_max` may be null). Any failure, including non-finite input coordinates, becomes `ServiceError('Não foi possível carregar a previsão.')`.
- **`src/features/weather/wmo.ts`**: the UI-SPEC S3 table with 8 lucide icon keys and 5 weather tones. Unknown or non-integer codes fall back to "Tempo indefinido".
- **`src/features/weather/forecast.ts`**: `weekdayLabel` (index 0 is "Hoje") and `weekdayLong`. Both read the date from `Date.UTC` parts with static arrays and do not use `Intl` or `new Date('YYYY-MM-DD')`.
- **`useWeatherForecast`**: query key `['weather', roundedLat, roundedLng]`. It runs only when both coordinates are finite numbers, with a 30 min staleTime and 1 retry.
- **`WeatherCard`**: the now block, a stats row that wraps for large fonts, a horizontally scrolling 7-day strip that runs edge to edge, and the footer "Atualizado às HH:mm · Dados do tempo: Open-Meteo.com". It has a static skeleton (role progressbar), an error state with no cached data ("Previsão indisponível" plus "Tentar novamente"), and a stale state that keeps cached data and shows a CircleAlert warning. It shows no DemoBadge.
- **`WeatherDayColumn`**: 60 wide with a minimum height of 112. Today gets a background fill and a border. Each column has one a11y label in the "Sexta-feira, chuva, máxima 28 graus, …" form; the icons are hidden from accessibility.
- **Início**: when the farm has `center_lat`/`center_lng`, the "Clima agora" section shows WeatherCard. Otherwise it shows the DemoBadge with the legacy ClimateCard if a demo snapshot exists, or else a MapPin card "Previsão indisponível para esta fazenda". The temperature tile converts `r.value` with `convertTemperature`. `selectMetric` is unchanged. The legacy ClimateCard uses `formatTemperature` with the stored preference.

**2. [Rule 2 - Critical] Attribution kept in the stale state**
- **Found during:** Task 2
- **Issue:** UI-SPEC S3 replaces the footer with the stale warning, which would hide the attribution that CC BY 4.0 requires while data is still on screen.
- **Fix:** The stale state shows the warning and then a separate muted caption "Dados do tempo: Open-Meteo.com". The string is held in one constant, so the grep count stays at 1.
- **Commit:** b86f567

**3. [Rule 2] getForecast rejects non-finite coordinates before fetch**
- The hook already gates on finite coordinates. The service now checks as well, so `NaN` or `null` never reaches the API (T-02.2-21). This is covered by a test.
