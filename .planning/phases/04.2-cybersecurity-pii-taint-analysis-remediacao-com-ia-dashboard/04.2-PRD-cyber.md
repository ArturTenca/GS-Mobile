# PRD — Entrega da disciplina Cybersecurity (CitizenTech) + pedido do usuário

Fonte: slides do professor (enviados pelo usuário em 2026-11-16) + mensagem do usuário. Prazo: 19/11/2026 (entrega via Teams).

## A Missão Técnica (professor)
1. **Mapeamento de PII** — configurar novas regras no motor de parsing para detectar dados sensíveis (CPF, saúde, senhas).
2. **Taint Analysis** — rastrear o fluxo das informações coletadas e bloquear vazamentos em saídas inseguras.
3. **Tradução via IA** — utilizar o LLM para traduzir falhas técnicas em alertas claros de risco real ao cidadão.

## O que entregar (arquivo ZIP)
- **Código do novo Módulo** — pacote compactado com o código atualizado contendo as regras PII.
- **Auditoria do Protótipo** — evidências do Taint Analysis em ação.
- **Dashboard Atualizado** — vídeo com atividade e print de tela do painel gerando o indicador de Risco Cidadão.

## Pontuação (10,0)
- Robustez do motor de Parsing PII — 3,0
- Eficácia do Taint Analysis — 3,0
- Inovação com IA na remediação — 2,0
- Dashboard Executivo (Risco Cidadão) — 2,0

## Pedido adicional do usuário
- Aplicar sanitização em TODOS os campos de input contra SQL injection, XSS e outras vulnerabilidades.
- Verificar quaisquer erros na parte de login e corrigi-los.
