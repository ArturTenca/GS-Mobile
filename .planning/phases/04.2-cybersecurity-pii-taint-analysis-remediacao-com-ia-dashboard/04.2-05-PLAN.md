<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keyboard/paste -> form state | attacker-controlled text in all free-text fields |
| BrasilAPI/ViaCEP -> form -> DB | external text becomes stored data |
| client -> PostgREST/RPC | parameterized, but values stored then reused in alerts/push |
| web origin -> browser | CSP header outside the bundle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04.2-25 | Tampering | SQL injection via text fields | mitigate | parameterized supabase-js/RPC only (sqlAudit test, ESLint template-literal filter rule from plan 04); allowlist rejects quotes-semicolon-equals payloads; DB CHECKs from plan 03 |
| T-04.2-26 | Tampering | stored/reflected XSS on web | mitigate | RN Text only; noDangerousSinks test; angle brackets removed live; allowlist; map has no user text (existing test kept) |
| T-04.2-27 | Information Disclosure | PII typed into names/addresses leaking to alerts, push, Nominatim | mitigate | validateField blocks identity/contact/financial/credential/health/location categories; runtime guards (plan 04) as second layer |
| T-04.2-28 | Spoofing | bidi/zero-width/homoglyph in names | mitigate | stripInvisible removes U+202A-202E, U+2066-2069, U+200B-200F, U+FEFF; NFC normalization |
| T-04.2-29 | Tampering | external API text injected into form | mitigate | sanitizeFreeText on lookup results before state |
| T-04.2-30 | Elevation of Privilege | missing CSP on web build | mitigate | documented hosting header + automated policy test; residual risk accepted until hosting is chosen |
| T-04.2-SC | Tampering | npm/pip/cargo installs | accept | no new packages |
