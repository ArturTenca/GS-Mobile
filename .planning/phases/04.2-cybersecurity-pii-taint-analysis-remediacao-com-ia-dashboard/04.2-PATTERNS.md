## Shared Patterns

- **Service layer only:** screens/hooks never import `@/lib/supabase`; ESLint `no-restricted-imports` enforces it (exceptions listed in RESEARCH). Source: `src/services/thresholds.ts` 1-3.
- **Error handling:** services throw `ServiceError(MSG_CONSTANT, cause)`; UI shows constants only, never raw server text. Source: `thresholds.ts` 22-38.
- **UI state boilerplate:** `LoadingState` / `ErrorState onRetry` / `EmptyState` / `Notice`. Source: `analises.tsx` 93-130, `NotificationsSection.tsx` 97-101.
- **Styling:** `useTheme()` colors + `spacing` tokens + `StyleSheet.create` in `useMemo`; icons from `lucide-react-native/icons/*`; touch >= 48dp; icon+text+color for levels.
- **DB security:** `security definer` + `set search_path = ''` + `(select auth.uid())` + revoke/grant. Source: `008` 332-337, 388-390.
- **Double-submit lock:** `useRef` in-flight flag. Source: `useGenerateDemoData.ts` 12-31.
- **Never persist/log raw PII:** only `redact()` output and fingerprints of `(rule|sink|origin)`.
