| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-04.2-07 | Spoofing | weak passwords | mitigate | validatePasswordStrength (letter+digit, common list, e-mail local part); server min length/leaked-password protection is a documented human setting (plan 08) |

| T-04.2-09 | Information Disclosure | persisted selected-farm after logout | mitigate | clearUserScopedState on signOut |
| T-04.2-10 | Information Disclosure | raw server error text | mitigate | mapAuthError only returns constants; tests assert no input text is echoed |
