## Behavior
- validateField order: sanitize, max length, PII scan, allowlist (PII message wins, e.g. 'a@b.com' in name).
- Accepted: "João D'Ávila", "Sítio São José – Km 12", "R. 7 de Setembro, nº 45", "CEP 37130-000". Rejected: javascript:, SQLi, template-injection, backticks, `=`; angle brackets removed live.
- Input: `sanitize` prop; default none for secureTextEntry / numeric keyboards, else single-line. Auth e-mail uses sanitize="email".
- Validators wired: farm, profile name, sensor name, signup name. Existing messages kept.
- FarmFormStep: maxLength 120/160/120/80/60; lookup street/neighborhood/city pass through sanitizeFreeText. SensorNameStep maxLength 140 to 120.
- WEB_CSP: header-delivered; script-src has 'unsafe-inline' (srcDoc map iframe inherits it) plus unpkg/jsdelivr (Leaflet); tile hosts tile.openstreetmap.org and server.arcgisonline.com; no eval.
