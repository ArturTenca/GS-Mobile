## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | completeOnboarding writes | mitigate | Column-level grants + `areas_insert` requires is_demo=false (insert never sends is_demo); every write chained `.select('id')` so silent RLS zero-row updates fail |
| T-02-02 | Tampering | form input | mitigate | validateOnboarding trims, enforces length limits and UF whitelist; DB check constraints remain the backstop |
| T-02-03 | Information disclosure | save error text | mitigate | ServiceError carries only the PT-BR copy; raw error only in `.cause` |
| T-02-04 | Elevation of privilege | forging onboarding_completed_at | accept | Worst case is the user skipping own onboarding; no data of others reachable |
| T-02-05 | Repudiation/Integrity | double submit duplicates area | mitigate | find-or-update single non-demo area + useRef in-flight flag + disabled form |
