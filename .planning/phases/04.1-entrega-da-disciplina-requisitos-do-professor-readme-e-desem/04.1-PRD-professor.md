# PRD — Entrega da disciplina Mobile Development & IOT (CitizenTech)

Fonte: enunciado do professor (copiado pelo usuário em 2026-11-15). Prazo: 19/11/2026 23h55 (link do GitHub no Teams, um integrante).

## Conceito
O app é a porta de entrada da CitizenTech: é por ele que o cidadão consulta, registra e recebe informação. A equipe aplica React Native com TypeScript, Expo Router, consumo de APIs e banco de dados para levar a solução até o celular de quem convive com o problema.

## Objetivo
Entregar um app funcional em Expo que resolva a jornada principal do cidadão definida na Ficha. O app deve:
- consumir dados de uma API ou de um mock;
- salvar informações em banco de dados;
- ser simples e acessível para quem não é especialista.

## Entregáveis (repositório GitHub)
- Código do app organizado.
- README com: a Ficha da CitizenTech, instruções para rodar o app, prints das telas.
- Link do vídeo de até 3 minutos com o app rodando (no README).

## Avaliação (0 a 10, 6 critérios)
1. Telas e navegação
2. Consumo de dados
3. Banco de dados
4. Acessibilidade
5. Aderência ao problema
6. Documentação

## Requisito adicional do usuário
- O app não pode demorar para carregar: tudo leve e rápido, sem demora (tempo de abertura, carregamento das telas e dos dados).

## Notas
- O conteúdo exato da "Ficha da CitizenTech" não está no repositório; o README deve ter a seção com os campos a preencher a partir do que o projeto já define (.planning/PROJECT.md), marcando o que a equipe precisa confirmar.
- Vídeo e prints: gravados/capturados por humanos; o plano deve preparar pastas, roteiro do vídeo de 3 min e placeholders no README, e um checkpoint humano para inserir os arquivos.
