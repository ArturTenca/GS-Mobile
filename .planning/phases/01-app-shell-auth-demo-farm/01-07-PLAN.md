<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app -> PostgREST/RPC | Authenticated JWT; RLS evaluates `auth.uid()` |
| service layer -> UI | Typed data and fixed PT-BR errors only |
| session -> query cache | Cached server data must not outlive the session |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information disclosure | Cross-account data via PostgREST | mitigate | Per-owner RLS from plan 02; UAT step 8 verifies two-account and anon isolation with real JWT claims |
| T-07-02 | Information disclosure | Stale cache shows previous account | mitigate | `queryClient.clear()` on logout (Perfil) and on user-id change (AuthProvider, plan 05) |
| T-07-03 | Tampering | Direct DB calls from screens bypassing validation | mitigate | ESLint `no-restricted-imports` restricts `@/lib/supabase` to services/auth/gate files |
| T-07-04 | Elevation of privilege | Client invoking clone for another uid | mitigate | Only `ensure_demo_farm()` (auth.uid()) is called from `properties.ts`; clone function is not client-executable (plan 02) |
| T-07-05 | Information disclosure | Raw server errors in UI | mitigate | `ServiceError` carries fixed PT-BR messages; raw error only on `cause`, never rendered or logged |
| T-07-06 | Repudiation | Accidental one-tap logout | accept | Confirmation Modal (UI-SPEC A1) |
| T-07-07 | Information disclosure | Mislabeled simulated data | accept | `is_demo` stays on every row (plan 02); Perfil badge only per user decision D-10; FND-09 flagged pending clarification |
</threat_model>
